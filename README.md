# Thiago Carmo - Portfolio Website

![Portfolio Preview](project%20screenshot.png)

A modern, interactive portfolio website showcasing development skills with a unique blend of contemporary design and nostalgic retro elements.

## 🚀 Technologies Used

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **3D Graphics**: Three.js for interactive 3D animations
- **Build Tool**: Vite for fast development and optimized builds
- **Icons**: Bootstrap Icons for consistent iconography
- **Deployment**: GitHub Pages with automated deployment

## 🎨 Key Features & Implementation

### Modern Design with Retro Elements
- **Terminal-inspired aesthetic** with animated UTF-8 characters and grid patterns
- **Windows 95-style blog interface** with draggable windows and authentic styling
- **Responsive design** that works seamlessly across desktop and mobile devices

### Interactive Components
- **3D rotating cubes** using Three.js for visual appeal
- **Animated skill cards** with autoplay videos showcasing technologies
- **Music player integration** with custom popup interface
- **Dynamic blog system** with localStorage for persistent content

### Technical Excellence
- **Modular JavaScript** with ES6 modules and clean separation of concerns
- **Advanced CSS animations** including glow effects, hover transitions, and keyframe animations
- **Mobile-optimized video autoplay** with fallback mechanisms for different browsers
- **Custom scrollbar styling** maintaining the terminal theme throughout

## 🌟 Why This Website Stands Out

1. **Unique Visual Identity**: Combines modern web design with nostalgic Windows 95 elements, creating a memorable user experience
2. **Technical Sophistication**: Implements complex animations, 3D graphics, and responsive design patterns
3. **Interactive Features**: Goes beyond static portfolios with draggable windows, music player, and dynamic content
4. **Performance Optimized**: Uses Vite for fast builds and efficient asset bundling
5. **Cross-Platform Compatibility**: Ensures consistent experience across devices and browsers

The website demonstrates both creative design skills and technical proficiency, making it an effective showcase for development capabilities.
